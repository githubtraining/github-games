# GitHub Games — Fork educacional

Este repositório é um fork com fins educacionais, desenvolvido na disciplina de **Gerenciamento de Projetos para Softwares Livres**.

## Sobre o jogo

O projeto é uma versão de Tetris para navegador, feita em JavaScript. O objetivo é encaixar as peças para completar linhas e marcar pontos. A partida também acompanha o número de linhas e o nível, e oferece prévia da próxima peça, temas visuais, efeitos sonoros, pausa, reinício e conquistas.

Para jogar, abra `index.html` em um navegador moderno.
